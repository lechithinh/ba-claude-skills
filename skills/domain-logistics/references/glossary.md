# Logistics glossary / Thuật ngữ vận chuyển và kho

| Term | Tiếng Việt | Meaning for a BA |
|---|---|---|
| Shipper / consignee | Người gửi / người nhận | Sender and receiver |
| Carrier / courier | Đơn vị vận chuyển | Company that moves parcels |
| 3PL / 4PL | Bên thứ ba / thứ tư cung cấp logistics | Outsourced logistics / orchestrator |
| AWB / waybill | Mã vận đơn | Unique parcel identifier |
| First / middle / last mile | Lấy hàng / trung chuyển / giao chặng cuối | Stages of delivery |
| Hub / sorting center | Bưu cục, trung tâm khai thác | Where parcels are sorted |
| POD | Bằng chứng giao hàng | Signature, photo, OTP proving delivery |
| Delivery attempt | Lần giao | One try at the address |
| RTS (return to sender) | Hoàn hàng về người gửi | After failed attempts |
| COD | Thu hộ tiền khi giao | Cash collected by courier |
| COD remittance | Đối soát và trả tiền COD | Courier pays collected cash to the shipper |
| Actual / volumetric / chargeable weight | Trọng lượng thực / quy đổi / tính cước | Chargeable = max(actual, volumetric) |
| Zone / rate card | Vùng / bảng giá cước | Price by zone, weight, service |
| Surcharge | Phụ phí | Fuel, remote area, oversize, COD fee |
| Declared value / insurance | Giá trị khai báo / bảo hiểm | Basis for compensation |
| SLA | Cam kết thời gian | Delivery time promise |
| WMS / TMS | Quản lý kho / quản lý vận tải | Warehouse and transportation systems |
| Inbound / putaway | Nhập kho / xếp hàng lên vị trí | Receiving and storing |
| Pick / pack / outbound | Lấy hàng / đóng gói / xuất kho | Order fulfillment |
| Wave / batch picking | Gom đơn lấy hàng | Picking efficiency methods |
| Bin / location | Vị trí kho | Storage location |
| Lot / serial | Lô / số seri | Traceability units |
| FIFO / FEFO | Nhập trước xuất trước / hết hạn trước xuất trước | Stock rotation |
| Cycle count | Kiểm kê định kỳ | Counting subsets regularly |
| Cross-dock | Chuyển tiếp không lưu kho | Receive and ship out quickly |
| Dispatch / route | Điều phối / tuyến giao | Assigning parcels to couriers/routes |
| Claim | Khiếu nại bồi thường | Lost or damaged parcel |
| Reverse logistics | Logistics ngược | Returns flow |
