# Logistics KPIs

| KPI | Meaning | Requirement implications |
|---|---|---|
| On-time delivery rate | Delivered within SLA / delivered | SLA calculation per zone and service |
| First-attempt success rate | Delivered on first try | Failed-reason capture, notifications |
| Return-to-sender rate | RTS / shipments | Attempt rules, reason codes |
| COD remittance time and accuracy | Days to remit; mismatches | Reconciliation tooling |
| Cost per parcel | Total cost / parcels | Pricing and cost reporting |
| Loss and damage rate | Claims / shipments | Claim workflow, evidence |
| Scan compliance | Parcels with all expected scans | Scan validation, exception queue |
| Pickup success rate | Picked up on time | Dispatch and scheduling |
| Pick accuracy and units per hour | Warehouse picking quality and speed | Pick task design |
| Dock-to-stock time | Receiving to available | Inbound flow |
| Inventory accuracy | Counted vs system | Cycle count rules |
| Order cycle time | Order to handover | Fulfillment SLA |
