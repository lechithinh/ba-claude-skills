# Lending glossary / Thuật ngữ cho vay

| Term | Tiếng Việt | Meaning for a BA |
|---|---|---|
| LOS / LMS | Hệ thống khởi tạo / quản lý khoản vay | Origination system vs servicing system |
| Application | Hồ sơ vay | Customer's request with documents |
| Credit bureau (CIC) | Trung tâm thông tin tín dụng | Source of credit history |
| Credit scoring / scorecard | Chấm điểm tín dụng | Model output used in decision |
| Auto-decision / manual review | Duyệt tự động / thẩm định thủ công | Straight-through vs analyst |
| DTI | Tỷ lệ nghĩa vụ trả nợ / thu nhập | Debt service vs income |
| Principal / interest | Gốc / lãi | Loan amount vs cost of borrowing |
| Flat rate | Lãi suất tính trên dư nợ gốc ban đầu | Interest on original principal for the whole term |
| Reducing balance | Lãi suất tính trên dư nợ giảm dần | Interest on remaining principal |
| EIR / APR | Lãi suất thực / hằng năm | Annualised true cost; used for fair comparison |
| Amortization / annuity | Trả gốc lãi đều | Equal installments, mix shifts over time |
| Installment | Kỳ trả nợ | One scheduled payment |
| Grace period | Thời gian ân hạn | No principal (or no payment) for a period |
| Penalty interest | Lãi phạt quá hạn | Charged on overdue amounts |
| Early repayment fee | Phí trả nợ trước hạn | Fee when settling early |
| Disbursement | Giải ngân | Paying the loan out |
| Co-borrower / guarantor | Đồng vay / bảo lãnh | Additional obligor |
| Collateral | Tài sản bảo đảm | Asset securing the loan |
| DPD | Số ngày quá hạn | Days past due; drives actions and classification |
| Debt group / NPL | Nhóm nợ / nợ xấu | Risk classification; non-performing loans |
| Roll rate | Tỷ lệ chuyển nhóm quá hạn | Share moving from one DPD bucket to the next |
| FPD | Quá hạn kỳ đầu | First payment default |
| Restructuring | Cơ cấu lại nợ | Changing terms for a struggling borrower |
| Write-off | Xóa nợ | Remove from books, collection may continue |
| Provisioning | Trích lập dự phòng | Reserve for expected loss |
| Auto-debit | Trích nợ tự động | Direct debit of installments |
| E-contract / e-sign | Hợp đồng điện tử / ký số | Digital signing |
| Cooling-off / cancellation | Thời gian cân nhắc / hủy khoản vay | Right to cancel shortly after signing [confirm if applicable] |
| Approval authority matrix | Ma trận phân quyền phê duyệt | Who can approve by amount and risk |
