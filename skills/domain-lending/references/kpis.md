# Lending KPIs

| KPI | Meaning | Requirement implications |
|---|---|---|
| Approval rate / auto-decision rate | Approved / applications; share without manual touch | Decision rules, review queues |
| Time-to-yes / time-to-cash | Application to decision / to disbursement | Funnel steps, SLAs |
| Application funnel conversion | Drop-off by step | Analytics events per step, resume flow |
| First payment default (FPD) | First installment missed | Fraud and scoring checks |
| DPD30 / DPD60 / DPD90 | Share of balance overdue by bucket | Reporting and alerts |
| Roll rate | Movement between buckets | Collections strategy analytics |
| NPL ratio | Non-performing / total | Classification, reporting |
| Collection rate / cure rate | Recovered amount, accounts brought current | Case management |
| Cost of risk | Provisions + write-offs / portfolio | Risk reporting |
| Portfolio yield | Interest income / average balance | Pricing |
| Early repayment rate | Prepaid loans / loans | Fee and recalculation rules |
| Customer complaints | By type, resolution time | Complaint workflow |
