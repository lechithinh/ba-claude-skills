# Công cụ vẽ BPMN

| Công cụ | Loại | Dùng khi |
|---|---|---|
| **bpmn.io** (demo.bpmn.io) | Free, mã nguồn mở | Luyện vẽ, xem/sửa file `.bpmn` sinh từ skill; xuất `.bpmn/.svg/.png`, không cần đăng ký |
| **draw.io / diagrams.net** | Free | Có thư viện shape BPMN, tích hợp Drive/Confluence |
| **Lucidchart** | Freemium | Cộng tác real-time, template BPMN |
| **Miro / FigJam** | Whiteboard | Brainstorm AS-IS cùng stakeholder trước khi chuẩn hoá |
| **Camunda Modeler** | Free desktop | BPMN sẽ chạy tự động hoá thực tế |
| **Visual Paradigm / SAP Signavio** | Trả phí doanh nghiệp | Mô phỏng, quản lý quy trình tập trung |

Người mới: bắt đầu với bpmn.io hoặc draw.io. Chuyển sang công cụ doanh nghiệp khi công ty yêu cầu tích hợp BPMS.
