# Changelog

All notable changes to this project are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/), versioning follows [SemVer](https://semver.org/).

## [0.2.0] — 2026-11-07
### Added
- **Domain packs:** `domain-banking` and `domain-ecommerce` — glossary, processes, business-rule patterns, BA checklist, data model, integrations, regulatory touchpoints, KPIs.
- Method skills now load domain packs automatically; `requirements-linter` gains the **DOM** rule (missing domain scenario).
- Before/after domain showcase examples.
- Documentation website (GitHub Pages) with learning guides in English & Vietnamese.
- Domain pack template and domain-maintainer contribution guide.
- Banner, social preview image, FAQ, release zips for Claude.ai upload.

### Changed
- README (EN/VI) restructured: quick start first, clearer differentiation, usage recipes.

## [0.1.0] — 2026-11-07
### Added
- Method skills: `meeting-to-requirements`, `requirements-linter`, `functional-decomposition`, `user-story-writer`, `ba-diagrams`, each with `LEARN.md`.
- Clinic booking end-to-end case study.
- Claude Code plugin marketplace manifest, `AGENTS.md`, contribution templates.
