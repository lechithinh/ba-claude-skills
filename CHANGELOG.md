# Changelog

All notable changes to this project are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/), versioning follows [SemVer](https://semver.org/).

## [0.3.0] - 2026-11-08
First published GitHub release (downloadable zips for Claude.ai).

### Added
- **Method skills:** `bpmn-modeling` (BPMN 2.0 with token-run simulation), `screen-spec` (from a mockup image), `decision-table` (with `dt_check.py` for missing, conflicting and overlapping rule combinations), `edge-case-finder`, `api-spec` (OpenAPI 3.0 draft).
- **Domain packs:** `domain-payments`, `domain-lending`, `domain-logistics`.
- `functional-decomposition` upgraded to a full skill: spec JSON, lint, Mermaid, SVG, CSV and HTML explorer, examples and evals.
- Animated BPMN token demo in the README (`assets/bpmn-token-*.svg`, generated by `scripts/make_token_demo.py`) and interactive demo pages (`docs/demo/`).
- Social preview and README banner images.

### Changed
- Website restyled in a green-blue look, optimized for mobile; the home page lists all 10 method skills and 5 domain packs.
- README: install options moved into Quick start, English demo, wider Skill and Pack columns.

### Fixed
- Website pages whose tables were printed as raw Markdown, and `<role>`-style placeholders that disappeared (`scripts/build_docs.py` now normalizes Markdown for GitHub Pages).
- Horizontal overflow of the Quick start section on phones.

## [0.2.0] — 2026-11-07
### Added
- **Domain packs:** `domain-banking` and `domain-ecommerce` — glossary, processes, business-rule patterns, BA checklist, data model, integrations, regulatory touchpoints, KPIs.
- Method skills now load domain packs automatically; `requirements-linter` gains the **DOM** rule (missing domain scenario).
- Before/after domain showcase examples.
- Documentation website (GitHub Pages) with learning guides in English & Vietnamese.
- Domain pack template and domain-maintainer contribution guide.
- Banner, social preview image, FAQ, release zips for Claude.ai upload.

### Changed
- README (EN/VI) restructured: quick start first, clearer differentiation, usage recipes.

## [0.1.0] — 2026-11-07
### Added
- Method skills: `meeting-to-requirements`, `requirements-linter`, `functional-decomposition`, `user-story-writer`, `ba-diagrams`, each with `LEARN.md`.
- Clinic booking end-to-end case study.
- Claude Code plugin marketplace manifest, `AGENTS.md`, contribution templates.
